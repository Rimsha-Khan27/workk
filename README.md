Overview:

This document provides the monitoring and handling procedure for ELAD infrastructure alerts related to CPU usage, memory usage, virtual memory utilization, and disk space threshold breaches across identified servers.

Purpose of this Document:

The purpose of this document is to provide the operational steps to be followed whenever ELAD alert notifications are received for CPU, memory, virtual memory, or disk utilization issues on the listed servers.

Scope of Services:

This SOP covers:

• Memory usage alerts

• CPU usage alerts

• Virtual memory alerts

• Disk space threshold breach alerts

• Notification to WINTEL Operations team

• Incident reference validation and escalation process
